# Clariva Pages

Public GitHub Pages site for Clariva's download-focused homepage, legal pages,
and support content. The homepage links to the App Store and Google Play and
uses approved app screenshots from the sibling Clariva repository.

- Privacy Policy: `privacy/index.html`
- Terms of Service: `terms/index.html`
- Terms of Use (EULA): `eula/index.html`
- Support: `support/index.html`
- Search discovery: `robots.txt`, `sitemap.xml`, and `site.webmanifest`
